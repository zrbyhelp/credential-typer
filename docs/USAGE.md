# 使用指南

## 1. 启动桌面端

启动 `CredentialTyper.App` 后，程序会缩到系统托盘并监听 LAN TCP `47820` 端口。首次运行时桌面窗口会显示二维码和桌面指纹。

如果只想在命令行联调：

```powershell
dotnet run --project desktop/CredentialTyper.Cli -- serve
```

Windows 防火墙弹窗出现时，允许程序在“专用网络”通信。不要把端口暴露到公网。

## 2. 首次配对

1. 手机安装 debug/release APK，首次打开时设置主密码。
2. 在手机添加至少一个账号，然后打开“扫码配对”。
3. 扫描桌面二维码；二维码有效期约 3 分钟，过期请在桌面刷新。
4. 桌面显示手机公钥指纹，和手机页面上的指纹逐组核对，确认无误后接受配对。
5. 配对记录保存在双方本机，之后连接不再需要二维码。

## 3. 填充凭据

将光标放到目标应用的账号或密码输入框，在手机账户详情页点击“填账号”或“填密码”。需要提交表单时，使用带“+回车”的按钮。

桌面端不会把密码写入剪贴板，也不会在日志中打印明文。部分以管理员权限运行的程序会被 Windows UIPI 拒绝注入；请让桌面端与目标程序保持相同权限级别。

## 4. 断线和换电脑

手机会自动尝试 KK 重连。更换电脑时，先退出旧桌面托盘进程，在新电脑刷新二维码后重新配对。若公钥指纹变化，必须重新核对并接受配对，不要忽略警告。

## 5. 加密备份

在手机设置中导出加密保险库文件，并将其存放在离线或受保护的位置。导入备份需要主密码；项目不会上传备份，也没有密码找回服务。
