# Credential Typer v1.0.6 · Windows 桌面端

## 更新内容

- 将桌面端 ChaCha20-Poly1305 改为纯托管 RFC 8439 实现，兼容 Windows 10。
- 修复部分系统因缺少系统 ChaCha20 算法导致扫码配对失败的问题。
- 保持与手机端 Noise IK/KK 和协议 v1 的字节级兼容。
- 单文件自包含发布，目标电脑无需安装 .NET。
