# Credential Typer v1.1.0 · Android 手机端

本版本更新手机 App，桌面端继续使用 [v1.0.6](https://github.com/zrbyhelp/credential-typer/releases/tag/v1.0.6)。Android `versionCode=4`，可直接覆盖安装。

## 更新内容

- 新增查看密码：再次验证主密码后查看/复制，剪贴板 30 秒自动清空。
- 新增加密保险库导出/导入（`.ctvault`）。
- 修复窗口感知排序，桌面焦点变化后实时更新。
- 新增自动锁定：切后台立即锁定，前台静置 3 分钟后锁定。
- 新增 Cloudflare R2 加密备份，上传和下载始终为保险库密文。
